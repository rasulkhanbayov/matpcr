WHAT EXPERIMENT 1 CHECKS
Two independent tests per oracle:
- Half-A (positive control): inject known-wrong claims into real data, confirm the oracle
  catches them. This checks the oracle's code is not buggy.
- Half-B (precision audit): manually review >=100 real cases where the oracle fired on
  real model outputs, and judge whether it was actually right to fire. This checks the
  oracle isn't too trigger-happy on real, messy data.
